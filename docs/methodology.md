# Methods summary

**Data.** RSNA Pneumonia Detection Challenge Stage-2 (26,684 DICOM images, lung-opacity labels, 22.5% positive) split into development (18,678; five folds), calibration (2,669) and locked test (5,337). External cohort: Kermany pediatric test set (624 JPEG images from 427 patients; 390 pneumonia, 234 normal).

**Preprocessing.** MONOCHROME1 inversion, per-image 0.5–99.5 percentile intensity scaling, three-channel conversion, bicubic resize to 320×320 and ImageNet normalization. Training-only augmentation: horizontal flip (p = 0.5), random rotation within ±5° and brightness/contrast jitter (factor 0.10), the latter two applied to every training image (torchvision defaults, no probability gate). Percentiles are computed per image, so no statistic is learned from any partition. InceptionV3 uses `transform_input=True`.

**Backbones.** torchvision InceptionV3 and Swin-B, `IMAGENET1K_V1` (`DEFAULT`) weights, one-logit heads. AdamW (learning rates 1e-4 and 5e-5, weight decay 1e-4), cosine schedule, mixed precision, 60 epochs, batch size 4 with 4 accumulation steps. Final models were trained on a label-stratified 88% of development; the remaining 12% served only for checkpoint selection (highest validation ROC-AUC, ties broken by lower BCE). Software: Python 3.13.12, PyTorch 2.10.0, torchvision 0.25.0, CUDA 12.8, NVIDIA A100-SXM4-40GB.

**Fusion.** Gate input per image: `[p_inception, p_swin, entropy_inception, entropy_swin, |p_inception − p_swin|]`; a 5–16–1 MLP (113 parameters) outputs the InceptionV3 weight. Matched controls: each backbone, equal mean, a learned constant weight (0.447, same out-of-fold BCE objective) and logistic stacking on logits. All fusion rules were fitted on development out-of-fold scores.

**Calibration and threshold.** Each of the six candidates has its own temperature and balanced-accuracy threshold, fitted only on the RSNA calibration split (`configs/historical.json`). They were frozen before the KermanyNorm evaluation, but they were refitted after the InceptionV3 `transform_input` fix, which was made after the first test scores had been seen, and the constant-weight and stacking controls were locked after initial backbone test scores existed (see [Limitations](limitations.md)).

**External evaluation.** Frozen: no Kermany labels are used for fitting. Prior-shift diagnostics use EM prior estimation (no labels) and a true-prevalence reference.

**Retrospective local adaptation (separate).** Labeled Kermany subsets of n ∈ {10, 20, 50, 100, 200}, 500 draws per budget, each stratified draw containing ⌊0.625n⌋ pneumonia cases and the rest normal; unstratified draws as a comparator. Evaluation always uses the remaining images. Decision thresholds: threshold-only re-selects the BA-optimal threshold; intercept-only keeps the frozen RSNA threshold; logistic recalibration uses the labeled-subset prevalence. Single-class draws are excluded; no fit failed to converge.

**Analyses kept separate.** (1) frozen historical models; (2) corrected development analysis; (3) exploratory corrected fold ensemble; (4) retrospective local adaptation; (5) latency benchmark. Their checkpoints and results must not be mixed.

**Explainability.** InceptionV3 Grad-CAM and Swin-B Integrated Gradients explain their own branch. Qualitative panels target the gate-predicted class, deletion faithfulness uses each branch's predicted class and RSNA localization uses the pneumonia class. Deletion-based AOPC measures sensitivity to perturbation, not clinical causality. The qualitative example panels show one case per confusion group, taken from the three cases ranked highest by a fixed rule (gate confidence for TP/TN; entropy plus branch disagreement for FP/FN). The displayed TP and TN cases rank second and the FP and FN cases rank first. For display only, each map was clipped at its 99.5th percentile, smoothed with a Gaussian kernel (σ = 2 px), cut below 0.035 and scaled to 0–1; deletion and localization metrics use the unsmoothed maps.
